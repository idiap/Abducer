# Calibrate Restricted Models

## Purpose

Require every proposed invariant and transfer theorem to recognize known massive, gapless, topological, finite-dimensional, and hidden-sector behaviors before applying it to four-dimensional Yang--Mills.

## Calibration Suite

Test at least:

- a finite positive transfer matrix;
- massive and massless Gaussian fields;
- a finite-volume sequence converging to a gapless theory;
- a direct sum with a hidden gapless sector;
- a model with spatial clustering but insufficient temporal information;
- a topological theory with no local propagating modes;
- a controlled spin or lattice gauge model in a convergent high- or strong-coupling regime;
- lower-dimensional gauge theories when their exact distinctions are relevant;
- regulated four-dimensional Yang--Mills only at the rigor level actually available.

## Workflow

1. Compute the proposed rigidity witness and all physical-unit normalizations.
2. Check observable-sector completeness.
3. Run each representation morphism and record which certificates survive.
4. Verify that transfer theorems accept genuinely massive cases and reject gapless false positives.
5. Separate regulator-specific strong-coupling results from cutoff-uniform continuum conclusions.
6. Refine or reject any definition that fails a calibration.

Previous Wilson-action work is optional late calibration, not a default foundation. Use it only when regulator-specific comparison is explicitly needed.

## Output Contract

Return a model-by-property matrix, explicit computations or citations, passed and failed tests, counterexamples, and resulting changes to definitions or claims. A framework that has not survived the massless and hidden-sector tests must not be used for a Clay-level conclusion.
