# Route A Paper Attack Orchestrator

## Purpose

This skill turns the Route A paper's open modules into an active result-production programme. It is not a discovery marathon skill and it is not a narrative expander. It coordinates focused proof, construction, estimate, and certificate attempts for the last paper draft.

## Priority Logic

1. **G1 first:** no geometric-collar claim is possible without explicit cutoff-indexed paths with positive-time support, reflection pairing, locked footprint, and joint \(a_k,\delta\) scaling.
2. **G2 second:** no normalized collar block is usable unless every removed factor is a same-theory congruence, direct observable normalization, or positive-kernel factorization.
3. **G3 third:** no Schur--Feshbach collar theorem exists until \(H_k,K_k\) and the \(o(\delta^2)\) remainder are derived from the same normalized geometric block.
4. **G4 after G1-G3:** strict margins require lower bounds, not boundedness or nonnegativity.
5. **E1-E2 downstream:** endpoint work is meaningful only after the geometric paths and normalization are fixed.
6. **M1-M2 are boundary modules:** keep continuum reconstruction and spectral gap as guarded handoffs unless earlier modules genuinely create a same-theory bridge.

## Workflow

1. Load the latest Route A narrative draft and the open-module analysis report.
2. Select the highest-priority unresolved module whose dependencies are satisfied.
3. Invoke the corresponding specialist skill:
   - `routea-geometric-collar-builder` for G1.
   - `routea-same-theory-normalization-certifier` for G2.
   - `routea-geometric-coefficient-extractor` for G3.
   - `routea-margin-endpoint-certifier` for G4/E1/E2.
   - `routea-continuum-gap-gatekeeper` for M1/M2.
4. Require an artifact-level result: theorem candidate, counterexample/demotion, exact calculation, certified bound plan, or paper patch.
5. Invoke `routea-paper-result-integrator` before any manuscript edit. Validated mathematics must become paper-native theorem/proposition/lemma/certificate/demotion text, never process narration.
6. Run claim-boundary review: finite source-collision, geometric collar, endpoint, continuum, and gap statements must remain separated.
7. Update the Route A TODO queue and paper integration target.


## Epistemic Discipline

Treat each manuscript result as a mathematical object with an explicit epistemic status: proved, certified finite, conditional, conjectural, blocked, or demoted. Cite evidence through source artifacts, paper labels, validation reports, deterministic script outputs, or explicit unknowns. Preserve the finite/geometric/endpoint/continuum claim boundary, and end with a validation handoff or unresolved obligations.

## Output Contract

Return: active module, dependency status, attempted mathematical move, generated definitions or estimates, deterministic checks, generative reasoning summary, promotion/demotion decision, paper insertion target, result-integration status, and next TODOs.

## Failure/Demotion

Demote the run if it only restates the open module, describes the problem without attempting an object-level construction or estimate, imports source-collision formulas as geometric-collar proof, writes paper prose before the mathematical object is stable, or lets workflow/pipeline/TODO language into the paper.
