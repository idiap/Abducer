## Candidate Lemma

Consequently C(H_N^SAT)<=N^{rho+o(1)}+Gamma_bEF(pi). If this upper bound is below N^{1+epsilon-o(1)}, it is a falsifier for the source lower-bound sentence LB_N(1+epsilon), not a proof of P != NP.

## Assumptions

# MCSP / Meta-Complexity Carrier Transfer

## Candidate Lemma

Conditional bit-explicit parser lemma: let Psys_bEF be EF with acyclic bit-level extension definitions, witnessed SATeq quotient edges, and bounded-SR_h rules with declared cover exponent eta and verifier exponent tau. Any accepted Psys_bEF proof pi_N whose lower-bound route for H_N^SAT is mediated by row-parity binding parses to an occurrence transcript Q_pi with cost Gamma_bEF(pi). If N^{rho+o(1)}+Gamma_bEF(pi)<N^{1+epsilon-o(1)}, then the routed statement LB_N(1+epsilon) is false in the unrestricted circuit model; this is a route-specific falsifier, not P != NP.

## Definitions

- source object: a bit string pi_N accepted by the Cook-Reckhow checker V_bEF for a beta-zero statement about H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with M_N=N^{q+o(1)} and bit-explicit formula codes G_N(x,j).
- target object: an unrestricted Boolean circuit upper bound for H_N^SAT on N input bits, or equivalently a falsifier for the asserted lower-bound sentence LB_N(1+epsilon): C_ckt(H_N^SAT)>N^{1+epsilon-o(1)}.
- controlled interface: a parser P_bEF that maps pi_N to Q_pi=(K_idx,Dep,Link,SR,Exc), recording row indices, extension-DAG dependencies, witnessed SATeq links, bounded-SR_h witnesses, and exceptional rows.
- target-preserving condition: every formula-identity or SAT-equality use must have an advice-free witness inside pi_N, bounded-SR_h witnesses must be checkable in the stated exponent regime, and FormulaEval-SAT must not be used as an unwitnessed semantic oracle.

## Assumptions

- Length regime: N tends to infinity, M_N=N^{q+o(1)}, generator size is N^{rho+o(1)}, each generated SAT instance has polylogarithmic bit length, and all o(1) terms are uniform over the proof family.
- Proof model: Psys_bEF lines are bit strings naming Boolean formulas, EF extension variables e:=phi have an acyclic definition DAG, SATeq axioms are only syntactic or witnessed extension-congruence equalities, and bounded-SR_h rules carry explicit local witnesses.
- Ledger definitions: S_dep(pi) is the number of reachable extension-DAG bits and wires, S_link(pi) is the total size of witnessed SATeq quotient data, N^{q+eta+tau+o(1)} charges bounded-SR_h over all SAT-query rows, and E_N is the number of exceptional rows patched directly.
- Circuit target: circuits are unrestricted and nonuniform, so the parsed transcript may be hardwired, but the parser, generator, and proof checker are advice-free uniform algorithms.
- Binding premise: Q_pi must be row-parity binding, meaning two completions of unparsed occurrences consistent with Q_pi give the same xor_{j<=M_N} SAT(G_N(x,j)) for every x outside Exc.
- Non-claim boundary: the lemma does not prove LB_N, does not prove P != NP, and does not handle Psys_sym lines using unwitnessed FormulaEval-SAT.

## Equations

- row_count: `M_N = N^{q+o(1)}`. Valid when: Valid when the beta-zero generator family is fixed uniformly and M_N counts all SAT-query rows.
- gamma_ledger: `Gamma_bEF(pi)=S_dep(pi)+S_link(pi)+N^{q+eta+tau+o(1)}+E_N N`. Valid when: Valid when Psys_bEF lines use only witnessed SATeq and bounded-SR_h rules with declared exponents.
- parser_size_bound: `|Q_pi| <= Gamma_bEF(pi)`. Valid when: Applies after the extension-DAG traversal records every dependency, link, support, and exceptional row.
- circuit_upper_bound: `C_ckt(H_N^SAT) <= N^{rho+o(1)}+Gamma_bEF(pi)`. Valid when: Requires the transcript to be row-parity binding and the generator circuit to be E-uniform.
- lower_bound_falsifier: `N^{rho+o(1)}+Gamma_bEF(pi)<N^{1+epsilon-o(1)} => not LB_N(1+epsilon)`. Valid when: Valid when LB_N(1+epsilon) asserts unrestricted circuit lower bounds in the same length regime.

## Attempted Derivation

- Define a Psys_bEF line as a tagged bit string: EF-definition, propositional inference, SATeq-witness, bounded-SR_h witness, or lower-bound assertion over the fixed generator G_N.
- Induct over the proof order. For propositional and EF lines, add only reachable extension-DAG dependencies to Dep; acyclicity gives a transitive traversal charged by S_dep(pi).
- For each SATeq line, require an explicit syntactic equality path or extension-congruence witness between formula codes; add the path to Link and charge its bit length to S_link(pi).
- For each bounded-SR_h line, enumerate the declared row-local witness family, verify it using the stated overhead tau, and charge the all-row cover by N^{q+eta+tau+o(1)}.

- Assuming row-parity binding, build a circuit for H_N^SAT by hardwiring Q_pi, computing G_N with N^{rho+o(1)} gates, evaluating the transcript-controlled SAT labels, directly patching Exc, and taking xor.
- Conclude C_ckt(H_N^SAT)<=N^{rho+o(1)}+Gamma_bEF(pi). If this is below N^{1+epsilon-o(1)}, LB_N(1+epsilon) is false, so a sound proof system cannot validate that routed certificate.

Blocking gap: The derivation is not yet a complete proof because bounded-SR_h still needs a bit-level witness grammar and the Psys_sym FormulaEval-SAT rule is not classified as witness, axiom schema, extension rule, or semantic oracle for every intended proof line.

## Falsifiers
