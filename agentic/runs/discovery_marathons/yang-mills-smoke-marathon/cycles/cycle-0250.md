- source object: heat-kernel plaquette-sheet regulated endpoint boxes v with local Wilson partition functions Z_{v,a}(J) and the locked Feshbach null incidence vector eta_v.

- same-theory condition: the sources are only infinitesimal Wilson plaquette-sheet flux insertions generated by the original loops; no boundary counterterm, diagonal renormalization change, or enlarged observable algebra is inserted.

- Check the local nonabelian commutator contact: on every straight boundary edge the oriented null incidence sum is zero, so the f^{ACD}f^{BCD} straight contact contributes no scalar endpoint weight. Only endpoint/corner boxes and tails remain.
