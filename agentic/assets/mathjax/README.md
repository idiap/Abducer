Vendored MathJax component for the discovery marathon reports.

`tex-svg.js` is embedded directly into generated HTML by
`agentic/scripts/generate_discovery_marathon_html.py` so the reports can be
opened offline with equations rendered and without runtime CDN dependencies.

Source component: `mathjax@3/es5/tex-svg.js`.
