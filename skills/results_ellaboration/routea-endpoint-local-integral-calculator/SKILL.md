# Route A Endpoint Local Integral Calculator

## Target

Derive the local endpoint estimator ingredients from the same paths and regulator:

- endpoint boxes;
- source variables;
- path-pair incidence tensor;
- \(SU(2)\) trace and singlet normalization;
- null-channel weights \(2,-4,-4\) after zero-diagonal normalization.

## Deterministic Support

Use `derive_routea_endpoint_incidence.py` on validated edge-list payloads. It computes endpoint memberships, pair incidences, diagonal cancellation conditions, and null-channel weights.

## Generative Work

Interpret the local group integral:

- choose exact group integration, character expansion, or local cumulant expansion;
- state the color normalization convention;
- explain whether the result is source-collision endpoint bookkeeping or a geometric-collar endpoint claim.


## Epistemic Discipline

Treat each manuscript result as a mathematical object with an explicit epistemic status: proved, certified finite, conditional, conjectural, blocked, or demoted. Cite evidence through source artifacts, paper labels, validation reports, deterministic script outputs, or explicit unknowns. Preserve the finite/geometric/endpoint/continuum claim boundary, and end with a validation handoff or unresolved obligations.

## Output Contract

Return: endpoint boxes, incidence tensor, null vector, off-diagonal weights, color convention, local integral form, missing analytic constants, sign-claim boundary, and manuscript lemma/proposition or demotion.

## Failure/Demotion

Demote if endpoint signs are inferred from the schematic template, color normalization is absent, or source-collision and geometric-collar endpoints are mixed.
