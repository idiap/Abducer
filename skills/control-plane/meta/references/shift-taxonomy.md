# Shift Taxonomy

Classify each major reflective finding using one of these labels.

## `perspective-shift`

The search changed the way the main problem is framed.

Example:

- direct proof aspiration became a sharper nonuniform target plus grounding implication.

## `sharpening`

The same route remained active, but became more mathematically explicit.

Example:

- a hidden transport was replaced by a typed bridge object and named invariant.

## `persistence`

The process clarified that a difficulty remains essentially unchanged.

Example:

- the route is still blocked by missing transfer lemmas and lack of adversarial evidence.

## `unresolved-defect`

The process exposed a structural defect that is now explicit but not fixed.

Example:

- two bridge operationalizations remain live without an equivalence theorem.

## `regression`

The process widened the search while reducing clarity, testability, or grounding.

Example:

- more obligations were generated without improving theorem-body specificity.
