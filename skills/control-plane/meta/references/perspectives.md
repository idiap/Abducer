# Meta Perspectives

Use one perspective explicitly when invoking `meta`.

## `epistemic`

Focus:

- what the search learned about the inferential bottleneck;
- which kinds of evidence are still missing;
- whether the discovery reduced uncertainty or only reorganized it.

Use when the question is:

- what changed in understanding;
- why the problem still resists closure;
- whether the framework is truth-tracking or only structure-tracking.

## `proof-programme`

Focus:

- the current route as a conditional theorem programme;
- what proof debt remains;
- which intermediate results would materially close the route.

Use when the question is:

- what the current macro-proof really amounts to;
- what remains to complete the route;
- whether the programme is converging or stalling.

## `barrier-aware`

Focus:

- why the target problem is structurally blocked;
- which negative routes, obstructions, or representation defects persist;
- whether failure is revealing a major barrier.

Use when the question is:

- what the framework has learned from failure pressure;
- whether the current route may be impossible as stated;
- where a negative result would still be a major contribution.

## `expert-handoff`

Focus:

- what a human expert should now believe;
- which intermediate results are genuinely inspectable;
- what has become clearer enough for expert intervention.

Use when the question is:

- what to hand to a mathematician now;
- which insights are mature enough for expert inspection;
- how to summarize the present state without overclaiming.
