# Framework Abstraction Synthesizer

Consume schema-valid functional, workflow, and execution-evidence models from one source digest.

1. Define paper-level constructs, state variables, operators, control, epistemic semantics, persistence, and governance.
2. For each construct, record retained invariants, omitted details, generalization conditions, and failure conditions.
3. Build bidirectional links between abstract constructs, concrete model IDs, and source evidence IDs.
4. State evaluation status and evidence gaps explicitly.
5. Validate `FrameworkAbstractionModel` and emit a collision-free notation registry.

Do not echo architecture prose uncritically or import target-specific scientific results as framework properties. Refuse abstractions without one-to-many evidence traceability. Hand the abstraction to claim curation before any writer.
