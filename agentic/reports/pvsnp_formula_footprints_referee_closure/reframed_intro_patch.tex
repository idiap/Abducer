\title{Structured Certificate Lower Bounds for Label-Induced Hardness Predicates}

\begin{abstract}
Let a batched generator map each source input \(x\in\{0,1\}^n\) to a list of
short strings, and let an external Boolean labeling of those strings induce a
source Boolean function through a fixed row aggregator.  We study inputwise
\(1\)-certificates for the predicate that the induced source function has
circuit complexity greater than a threshold \(s_n\).

The main result is a formula-label footprint lower bound.  If a certificate
fixes only a small set of generated formulas of either polarity, then the
unfixed labels can be completed to a near-constant labeling.  A batched
sorting-network dictionary evaluates the exceptional labels for the entire row
batch at near-linear batch-plus-dictionary cost, yielding a small source
circuit and contradicting certificate soundness.  Thus any sound certificate
must expose near-threshold many distinct generated formulas of both polarities.

We also prove two supporting structural lemmas.  In the private occurrence
model, sparse-row patching forces many source rows of each output value, and
the row aggregator's forcing number converts this into an occurrence-query
lower bound.  For parity with sound equality identifications, the residual
completion space is an affine image, and soundness requires every remaining
completion to stay far from both constant functions.

These are certificate-complexity statements, not a proof of \(P\ne NP\), not a
proof that \(\mathrm{SAT}\notin\mathrm{P/poly}\), and not a lower bound for
Frege, Extended Frege, IPS, or another standard proof system.  The SAT parity
carrier is used only as a conditional calibration: if an explicit source lower
bound were proved, then any completion-sound local certificate interface would
have to pay the formula-footprint, row-forcing, or quotient-distance costs
identified here.
\end{abstract}

\paragraph{Scope and nonclaims.}
The results below are deliberately scoped.  We do not construct an explicit
SAT-labeled generator whose induced source function has unrestricted circuit
complexity above the threshold.  We do not claim that arbitrary proof systems
produce formula, occurrence, or quotient certificates; such a claim would
require a separate extraction theorem.  We also do not handle nonlinear SAT
semantic constraints, such as self-reduction, inside the equality quotient
model.  The contribution is a compact theorem package about structured
inputwise certificates for label-induced hardness predicates.
