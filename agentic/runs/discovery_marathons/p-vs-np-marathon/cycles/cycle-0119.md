## Definitions

- target-preserving condition: beta=0, q<1+epsilon, rho<1+epsilon, no hidden advice, same-theory occurrence expansion, and every semantic row influence used later is included in the prefix closure before the final LB_N inference.

- Gamma_comp(pi)=Gamma_bEF(pi)+U_N(pi)+X_N(pi)+R_N(pi) is prefix-compositional: if line t uses an earlier symbolic value, it inherits all row influences in that value's closure.

## Assumptions

- Circuit model is nonuniform SIZE over Boolean circuits with equality patches charged O(N) per bad source row.
- Length regime has N tending over valid carrier lengths, M_N=N^{q+o(1)}, L_N=polylog(N), and beta=0 target-query length for the SAT substitution bridge.
- Proof system regime is restricted Psys_sym^ext: extension variables have bit-explicit support or a declared support realizer; FormulaEval lines are extensional unless explicitly discharged by RealSATInfluenceRealizer_N.
- Uniformity/advice regime is advice-free for the parser: enumerators, selector codes, closure maps, and expansion witnesses are present in pi or generated by a fixed polynomial-time parser, not supplied as semantic advice.
- Same-theory condition: every expanded row formula and every SATeq/SR_h leaf refers to the same generated G_N(x,j) instances used by H_N^SAT, with no off-range semantic oracle.
- Naturalness/barrier status: the theorem is a parser/falsifier boundary and is not a large constructive property of SAT truth tables; full semantic RealSATInfluenceRealizer_N is explicitly nonrelativizing and not proved here.

## Definitions

- source object: Psys_sym^TRS proof pi of LB_N(1+epsilon) for H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with N=2^n, M_N=N^{q+o(1)}, and generator size N^{rho+o(1)}.
- target object: row-expanded Psys_bEF^- transcript Exp_N(pi) and the same-model nonuniform SIZE upper-bound falsifier for H_N^SAT.

- Gamma_bEF(pi) is the already audited charge of bit-explicit bEF, SATeq, and bounded-SR_h lines.
- U_N is the total verifier-visible enumeration debt for FormulaEval row selectors; X_N is the explicit row-expansion debt for influenced rows.

## Assumptions

- Model is nonuniform Boolean SIZE over N-bit input x; reductions are parser/simulation transfers, not many-one reductions from SAT.
- Psys_bEF^- parser theorem is valid for bit-explicit bEF, SATeq, and bounded-SR_h rules with local occurrence neighborhoods and no hidden advice.
- Each FormulaEval line accepted by TRS_N has a topologically earlier row-template expansion or pays a full-scan charge before it can influence later proof lines.

- Uniformity regime is deterministic poly(|pi|,N) parsing with no oracle, no nonuniform selector advice, and all o(1) terms measured along N=2^n.

## Equations

## Candidate Lemma

For Psys_sym over H_N^SAT, TransparentRowSupport_N yields Gamma_trans(pi)=Gamma_bEF(pi)+U_N+X_N by line induction; any first uncharged semantic influence gives a private-row/unread-enable-bit countermodel. This is a parser falsifier theorem, not P != NP.

## Definitions

- source object: a bit-explicit Psys_sym transcript pi proving LB_N(1+epsilon) about H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with Psys_bEF^- core and FormulaEval lines.

- controlled interface: TransparentRowSupport_N gives visible selector code, advice-free row enumeration or full-scan charge, influence closure, occurrence expansion, and no hidden semantic support.
- target-preserving condition: the simulation stays in the same nonuniform SIZE model, uses no advice-selected row, and charges each semantic FormulaEval influence by U_N+X_N or rejects it by private-row falsifier.
- K_idx(pi) is the set of row indices whose SAT values influence the transcript after transparent closure; U_N is row-discovery cost; X_N is occurrence-level expansion cost.
- RealSATInfluenceRealizer_N is the open nonrelativizing, advice-free witness mechanism needed to convert real SAT semantic influence into visible charged rows.

## Assumptions

- Length regime: M_N=N^{q+o(1)}, formula length polylog N, generator circuit size N^{rho+o(1)}, and all o(1) terms are uniform over the proof family.
- Proof model: Psys_bEF^- core rules are bit-explicit and already have a valid Gamma_bEF line induction; FormulaEval is the only added symbolic mechanism.

- Same-theory condition: occurrence completions used in the countermodel preserve every read proof bit and alter only an uncharged FormulaEval influence.
- Barrier status: the positive theorem is sparse and non-large; the full semantic escape is an unwitnessed SAT-extensionality oracle unless RealSATInfluenceRealizer_N is supplied.

## Equations
