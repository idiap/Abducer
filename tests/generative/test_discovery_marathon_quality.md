# Discovery Marathon Generative Quality Probe

A valid marathon run should satisfy these human-review questions:

- Does each branch output name the mathematical source object and target object?
- Are equations accompanied by validity conditions, not merely displayed?
- Does the branch explain why a failed attempt teaches something and what should be tested next?
- Does the cycle show all required skill phases or an explicit skip reason?
- Does the report distinguish mathematical learning from workflow bookkeeping?
- Does the loop preserve target commitments while allowing backtrack, pivot, quarantine, and stop decisions?
