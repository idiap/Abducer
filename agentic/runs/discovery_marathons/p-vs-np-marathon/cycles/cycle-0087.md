# Hardness-Magnification Bridge Realization

## Candidate Lemma

Semantic-link residual code lemma: for the quotient-functional EF+SATeq_N fragment, any accepted short certificate soundly implying C(H_y)>S_N for every EqSAT-quotient-respecting label vector y must have residual parity distance delta_E(W,a_W)>=S_N/O(N). Thus delta_E(W,a_W)<N^{epsilon-o(1)} is a falsifier for the proof-mediated source lower-bound route.

## Definitions

- source object: H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)) with M_N=N^{q+o(1)} and L_N=(log N)^d.
- target object: a source lower-bound certificate for C(H_N^SAT)>S_N with S_N=N^{1+epsilon-o(1)}, used only through the beta-zero transfer toward SAT notin P/poly.
- controlled interface: EF+SATeq_N certificate parser producing an EqSAT quotient graph E, touched quotient classes W, and a quotient-functional predicate P(y|_W).
- target-preserving condition: q,rho<1+epsilon, beta=0, EqSAT witnesses are uniform/checkable, and no nonuniform SAT-label advice is inserted by the parser.
- EqSAT quotient graph E identifies generated formula occurrences whose satisfiability equality is justified by explicit EF-verifiable formula transformations.
- Residual parity distance delta_E(W,a_W) is the minimum row support of any quotient label vector matching the real SAT labels on W.

## Assumptions

- Circuit model is nonuniform Boolean circuits; patching one exceptional source row costs O(N) gates in the current row-residual normalization.
- Psys fragment is quotient-functional: after parsing, acceptance depends only on labels in W and soundness is required for all label assignments constant on EqSAT quotient classes.
- The transcript cost, link-checking cost, and parser overhead are o(S_N), so the only threshold-scale correction term is row patching.
- The proof is not claimed for arbitrary EF+SATeq_N; formula-semantic inferences not reducible to W,E remain the named open normal-form gap.
- The beta-zero target transfer is kept separate from this source-certificate lemma.

## Equations

- semantic_link_carrier: `H_y(x)=\bigoplus_{j\le M_N} y_{[(x,j)]_E}`. Valid when: Valid when E is the checkable EqSAT quotient graph and y assigns one Boolean label to each quotient class.
- residual_distance: `\delta_E(W,a_W)=\min_{z:\ z|_W=a_W}\left|\left\{x:\ \bigoplus_{j\le M_N} z_{[(x,j)]_E}=1\right\}\right|`. Valid when: Valid when the parser reads only W and soundness is tested over all quotient-respecting label assignments.
- sparse_row_upper_bound: `C(H_z)\le O(\delta_E(W,a_W)N)+\operatorname{cost}(Q)`. Valid when: Valid when row support is patched by equality tests of size O(N) and the transcript cost is subthreshold.
- necessary_distance_threshold: `\delta_E(W,a_W)\ge S_N/O(N)=N^{\epsilon-o(1)}`. Valid when: Valid when S_N=N^{1+\epsilon-o(1)} is the claimed source lower-bound threshold and parser overhead is o(S_N).

- Parsed a hypothetical short EF+SATeq_N proof into three observable components when possible: an EqSAT quotient graph E, a touched set W of quotient classes, and a predicate P depending on the real SAT labels only through W.
- For the quotient-functional fragment, assumed P(a_W)=1 and P(z_W)=1 for every quotient-respecting z matching a_W.
- Defined the residual parity code generated by the row-incidence map A_E from quotient classes to source rows and the coset constraint z|_W=a_W.
- If the coset has a representative z with row support delta<S_N/O(N), built an equality-patch circuit of size O(delta N)+cost(Q)<S_N for H_z.
- Because P cannot distinguish z from the real labels on W, quotient-functional soundness would assert C(H_z)>S_N, contradiction.
- Concluded that any valid quotient-functional certificate must prove residual distance at least N^{epsilon-o(1)}, not merely touch many raw occurrences or cite EqSAT soundness.

Blocking gap: The derivation does not produce a normal form for arbitrary EF+SATeq_N proofs. Full EF can use nonrelativizing SAT-semantic principles, formula self-reductions, and derived equality chains whose acceptance is not a predicate over a bounded W,E quotient transcript.

# Barrier-Aware Lower-Bound Route

## Candidate Lemma

Generator-local EF+SAT_U^comp certificates for the beta-zero XOR carrier have a dichotomy: if the proof admits a semantic-row closure K_pi of size o(N^epsilon), then a sparse residual circuit refutes the claimed source lower bound; otherwise the proof pays semantic full-row charge |K_pi|>=N^{epsilon-o(1)}. This is a route theorem for the named fragment, not a P != NP claim.

## Definitions

- source object: H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with M_N<=N^{q+o(1)}, |G_N(x,j)|=(log N)^d, and an asserted source lower bound C(H_N^SAT)>N^{1+epsilon-o(1)}.
- target object: a proof-mediated lower-bound certificate pi in P_gencomp=EF plus generator-local SAT equality, negation, and fanin-b composition axioms over the row formulas G_N(x,j).
- controlled interface: SemanticClosureParser(pi) returns the smallest row set K_pi containing every row explicitly projected by pi and closed under every generator-local SAT composition hyperedge used in pi.
- target-preserving condition: every completion that agrees with H_N^SAT on K_pi and with the spoof function D_N off K_pi keeps all P_gencomp axioms and verifier projections valid, so residual patching transfers to the same H_N^SAT truth table.

## Assumptions

- Model: P_gencomp is uniform EF with extension variables allowed only for proof syntax, while SAT_U atoms are restricted to generator-row formulas and named fanin-b row compositions appearing in the generator-local closure.
- Uniformity: G_N is computable by circuits of size N^{rho+o(1)} and every row formula has length polylogarithmic in N, so a row truth table over all x has O(N polylog N) hardwirable cost.
- Soundness regime: pi proves the lower-bound sentence LB_epsilon(H_N): C(H_N^SAT)>N^{1+epsilon-o(1)} and the certificate semantics are valid under all row completions satisfying the local SAT composition axioms.
- Threshold regime: there is a spoof D_N of size S_D=N^{1+epsilon-o(1)} that agrees with H_N^SAT outside K_pi; if |K_pi|=o(N^epsilon), patching contradicts LB_epsilon.
- Non-claim boundary: no assertion is made for full EF+SAT_U with arbitrary introduced formulas unless an extension-to-row realizer maps each semantic SAT atom to bounded generator-row closure.

## Equations

- beta_zero_carrier: `H_N^{SAT}(x)=\bigoplus_{j=1}^{M_N} SAT(G_N(x,j)),\qquad M_N\le N^{q+o(1)}`. Valid when: Valid when the source object is the beta-zero XOR carrier with generator rows indexed uniformly and no positive-beta input substitution is being smuggled into the transfer.
- semantic_closure_definition: `K_\pi=\operatorname{cl}_{\Gamma_\pi}(Q_\pi),\quad \Gamma_\pi=\{S\to j: \pi\text{ uses a generator-local SAT composition deriving row }j\text{ from rows }S\}`. Valid when: Valid when every SAT-semantic proof line in the named P_gencomp fragment references only generator-row atoms or declared generator-local composition hyperedges.
- sparse_residual_patching: `C(H_N^{SAT})\le S_D+O(|K_\pi|\,N\,\operatorname{polylog}N)`. Valid when: Applies after the completion agrees with the spoof circuit outside the semantic closure and each charged row can be hardwired over all N target inputs.
- forced_charge_threshold: `C(H_N^{SAT})>N^{1+\epsilon-o(1)}\ \land\ S_D\le N^{1+\epsilon-\eta}\ \Longrightarrow\ |K_\pi|\ge N^{\epsilon-o(1)}`. Valid when: Requires the source lower bound, a subthreshold spoof circuit, and the target-preserving residual patching inequality with polylogarithmic row-evaluation overhead.

## Attempted Derivation

- Fix P_gencomp: EF proof syntax plus SAT_U atoms Y_j(x) only for generator rows and declared fanin-b generator-local compositions; no SAT atom may mention an arbitrary extension formula.
- Given pi, scan each SAT_U composition axiom. Add a hyperedge S->j from premise rows S to conclusion row j. Let Q_pi be the rows explicitly queried by verifier projections or conclusion-local checks. Define K_pi=cl_{Gamma_pi}(Q_pi).
- Construct a spoof completion A^D: outside K_pi use labels induced by a candidate small circuit D_N for H_N^SAT; inside K_pi use the true SAT-row labels. Because K_pi is closed under all semantic hyperedges used by pi, every generator-local SAT axiom seen by pi has the same truth value under A^D as under the true table.
- Therefore pi cannot distinguish H_N^SAT from the completed spoof unless it projects a row in K_pi. If pi is accepted and soundly implies LB_epsilon(H_N), then the completed spoof must itself have circuit complexity above N^{1+epsilon-o(1)}.
- But the completed spoof is computed by D_N plus a lookup/row-patching circuit for each charged row, giving C(H_N^SAT)<=S_D+O(|K_pi|N polylog N).
- With S_D<=N^{1+epsilon-eta} and |K_pi|<=N^{epsilon-eta}, this contradicts the asserted source lower bound for sufficiently large N. Hence any valid P_gencomp proof must have |K_pi|>=N^{epsilon-o(1)} or avoid the assumptions.

Blocking gap: The derivation does not cover full EF+SAT_U because arbitrary extension formulas can be targets of SAT_U axioms without a proved ExtensionRowRealizer or bounded semantic-row support.

## Falsifiers

- Three-row OR triad: equality closure misses c although the valid SAT-composition axiom y_c <-> y_a OR y_b forces c into semantic closure.
- Arbitrary EF extension formula F encoding a global OR of many generator rows: one SAT atom SAT(F) can create semantic support of size M_N, defeating logarithmic occurrence parsing.
- Sparse residual falsifier: if a certificate leaves semantic closure |K|=o(N^epsilon), then D_N plus O(|K|N polylog N) patching gives a subthreshold circuit for H_N^SAT.
- Naturalization falsifier: if the proof instead yields a functional O(log N)-projection property useful against SIZE(N^{1+epsilon}), it becomes a large constructive natural property and faces PRF pressure for the same target class.

## Learning

Cycle 87 replaces the inadequate equality-closed invariant with semantic-row closure for a concrete generator-local EF+SAT_U^comp fragment. The route now has a valid restricted theorem: small semantic closure gives a residual falsifier, while sound certificates must pay N^{epsilon-o(1)} row charge. The full formula-semantic extraction fork remains open at the ExtensionRowRealizer for arbitrary EF SAT atoms, not at generic barrier folklore.

# MCSP / Meta-Complexity Carrier Transfer

## Candidate Lemma

For the beta-zero SAT-XOR carrier, any P_wExt proof whose formula-identity and equisatisfiability uses are witnessed by a low-adaptive-cover quotient yields the same patch upper bound as the occurrence-local parser. Thus such a proof cannot validly certify C(H_N^SAT)>N^{1+epsilon-o(1)} when the cap exponent is below 1+epsilon.

## Definitions

- source object: H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)) together with a P_wExt proof pi_N of a lower-bound sentence LB_N saying C(H_N^SAT)>N^{1+epsilon-o(1)}.
- target object: a nonuniform circuit upper-bound falsifier for H_N^SAT with exponent max{rho,q+alpha_ext,max(f,r)+1}.
- controlled interface: a parser maps SAT occurrences in pi_N to an equality/equisatisfiability quotient Q_pi, plus a label-opener for quotient classes with adaptive cover exponent alpha_ext.
- target-preserving condition: row-parity binding holds on all forced rows and the remaining semantic residual and unforced rows have exponents r and f, so the constructed approximant agrees with the real SAT parity off a patchable sparse set.
- P_wExt is EF plus SAT atoms and witnessed extensionality rules; every formula identity or equisatisfiability inference carries a syntactic witness such as definitional extension, variable renaming, or an EF-checkable Tseitin map.
- ForcedRows(Q_pi) are rows whose XOR of quotient labels is constant over all locally SAT-consistent assignments admitted by the parsed proof transcript.

## Assumptions

- Uniform generator regime: M_N<=N^{q+o(1)}, formula length L_N=(log N)^d, and G_N has circuits of size N^{rho+o(1)}.
- Proof-system regime: pi_N may be hardwired for the negative upper-bound direction, but every semantic identity used by P_wExt is witnessed and parsed into Q_pi; no unwitnessed SAT-extensionality axiom is allowed.
- Cover regime: the quotient-label opener has adaptive exponent alpha_ext and is nonuniformly available from pi_N; this is enough for a falsifier upper bound but not a uniform lower-bound consequence.
- Binding regime: for each forced row x, all LocSat(Q_pi)-consistent labelings give the true parity xor_j SAT(G_N(x,j)), except for a residual set R_N of size N^{r+o(1)}.
- Patch regime: the set B_N of unforced rows has size N^{f+o(1)}, and equality-to-row patches cost O(N) gates per exceptional row.

## Equations

- carrier_definition: `H_N^{SAT}(x)=\bigoplus_{j\le M_N} SAT(G_N(x,j)),\quad M_N\le N^{q+o(1)},\quad |G_N|\le N^{\rho+o(1)}`. Valid when: Valid when the source carrier is the beta-zero SAT-XOR family with polylogarithmic SAT instances and explicitly bounded generator overhead.
- adaptive_extensional_cover: `\alpha_{ext}=\max\{\tau,\max_\ell(a_\ell+\mu_\ell),\max_\ell\omega_\ell\}`. Valid when: Valid when witnessed formula identities contract to quotient-openers with transcript, summary, and local-opening exponents tau, a_l+mu_l, and omega_l.
- forced_rows_definition: `ForcedRows(Q_\pi)=\{x:\bigoplus_{j\le M_N} y_{[G_N(x,j)]}\text{ is constant over }LocSat(Q_\pi)\}`. Valid when: Valid when every SAT occurrence is assigned to a parsed quotient class and LocSat contains exactly the locally admissible quotient labelings.
- patch_upper_bound: `C(H_N^{SAT})\le N^{\max\{\rho,q+\alpha_{ext},\max(f,r)+1\}+o(1)}`. Valid when: Applies after row-parity binding is established on forced rows and all unforced or residual rows are patched by explicit equality tests.
- certificate_falsifier_threshold: `1+\epsilon>\max\{\rho,q+\alpha_{ext},\max(f,r)+1\}\Rightarrow \pi_N\text{ is not a valid certificate of }C(H_N^{SAT})>N^{1+\epsilon-o(1)}`. Valid when: Requires the lower-bound sentence to target unrestricted nonuniform circuits and the parsed proof transcript to satisfy the witnessed-extensionality cover assumptions.

## Attempted Derivation

- Fix N and hardwire the proof pi_N, its witnessed extensionality certificates, and the resulting quotient transcript Q_pi; this is legitimate because the conclusion is a nonuniform upper-bound falsifier.
- For each input x and query index j, compute G_N(x,j) using the beta-zero generator; cost contributes N^{rho+o(1)} globally and N^{q+o(1)} repetitions.
- Use the quotient opener to obtain the label y_[G_N(x,j)] for the parsed formula class; the total query-label cost is N^{q+alpha_ext+o(1)}.
- XOR the M_N labels to obtain an approximant D_N(x). By row-parity binding, D_N(x)=H_N^SAT(x) on forced nonresidual rows.
- Patch every unforced row and every residual row by equality tests against x; if |B_N|<=N^{f+o(1)} and |R_N|<=N^{r+o(1)}, the patch cost is N^{max(f,r)+1+o(1)}.
- Combine generator, opener, and patch circuits to derive C(H_N^SAT)<=N^{max{rho,q+alpha_ext,max(f,r)+1}+o(1)}.
- Therefore any proof claiming a larger unrestricted circuit lower bound is invalid within P_wExt under the stated binding and sparsity assumptions.

Blocking gap: The derivation does not cover P_uExt or full systems with unwitnessed SAT-extensionality; a semantic equality step without a parsed witness may identify formula occurrences in a way no low-cover quotient can reproduce.

## Falsifiers

- A single unwitnessed SAT-extensionality rule is a falsifier for the low-cover parser because the occurrence quotient may require semantic equivalence information absent from the proof transcript.
- If alpha_ext<1+epsilon-q and f,r<epsilon, the constructed circuit upper bound falsifies any claimed N^{1+epsilon-o(1)} lower-bound certificate in P_wExt.
- If row-parity binding fails, a private-label spoof on a nonforced row gives a countermodel to the proof-to-query extraction even when ordinary local soundness holds.
- If an MCSP/MKtP carrier has adaptive cover alpha_ad below its claimed threshold theta, the carrier supplies its own row circuit and is not a valid no-side source.
- If the proof uses nonuniform hard-row selection to choose labels but gives no advice-free searchable certificate, it may show aggregate hardness only and cannot transfer to a uniform language lower bound.

## Learning

Cycle 87 upgrades the formula-semantic fork by isolating a positive restricted theorem and a negative escape: witnessed extensionality contracts to a low-cover quotient and gives the valid upper-bound falsifier C(H_N^SAT)<=N^{max{rho,q+alpha_ext,max(f,r)+1}+o(1)}, while unwitnessed SAT-extensionality is the precise semantic principle not handled by the occurrence parser. This is route-level progress for the paper packet, not evidence for P != NP itself.
