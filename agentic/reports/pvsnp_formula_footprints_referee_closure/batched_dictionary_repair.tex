\paragraph{Patched batched dictionary proof.}
Create \(M\) query records and \(K\) hardwired dictionary records.  A query
record has the form
\[
  (q_i,1,i,0),
\]
where the second field is a query tag and \(i\) is the original query index.  A
dictionary record for key \(u\in D\) has the form
\[
  (u,0,0,a(u)).
\]
Sort the \(N=M+K\) records lexicographically by key and then by the tag, placing
the unique dictionary record, if present, before all query records with the same
key.  Batcher's sorting network has \(O(N\log^2 N)\) comparators, and a
comparator on records of width \(O(\ell+\log N)\) has size
\(O(\ell+\log N)\).

After sorting, perform a left-to-right scan inside each equal-key block.  The
scan records whether a dictionary record has appeared in the current block and
propagates its payload value.  Each query record therefore obtains the value
\(a(q_i)\) when \(q_i\in D\), and the default value \(b\) otherwise.  Dictionary
records are masked out at the output stage.  If the final aggregator is
symmetric, the circuit may aggregate the recovered values of the query records
in sorted order, since only their multiset matters.  If the aggregator is not
symmetric, sort all records once more by the query tag and then by the stored
original index, feed the first \(M\) query records to the aggregator, and ignore
the dictionary records.  The scan, masks, and optional second sort are absorbed
by the same
\[
  O\bigl((M+K)\log^2(M+K)(\ell+\log(M+K))\bigr)
\]
bound.  Thus original-order restoration is unnecessary only in the symmetric
case; query-record separation is required in all cases.
