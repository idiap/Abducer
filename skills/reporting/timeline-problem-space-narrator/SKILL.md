# Timeline Problem Space Narrator

## Workflow

Read the target literature report, macro strategy report, strategy judge, and accumulated timeline. Build a paper introduction that:

1. States the problem in accessible and formal terms.
2. Explains how the literature made the problem precise.
3. Names the historical route families and their unresolved obligations.
4. Connects the active timeline work to those obligations.

## Epistemic Discipline

Every historical claim must cite a reference ID or source artifact. Every active-route claim must cite a timeline cycle, report path, or explicit unknown. Label conjectural route interpretation separately from established literature.

Use evidence citations as first-class text: reference IDs, artifact paths, cycle IDs, and explicit unknowns must appear next to the claims they support.

## Output Contract

Return: problem statement, related-work chronology, route landscape, unresolved obligations, source citations, epistemic status, and validation handoff.

## Failure/Demotion

Demote the section if it becomes generic history, omits references, hides unresolved obligations, or treats the active route as established literature.

## Validation Handoff

Check that cited references exist in `agentic/reports/target_literature_evolution/latest.json` and that timeline claims cite cycle IDs or report paths.
