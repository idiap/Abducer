# Framework Paper Evaluation Writer

Consume only blueprint, ledger, execution-evidence model, and optional authorized `result-packet.json`.

Accept empirical results only when the packet binds protocol ID, authorization, receipt digests, metric definitions, uncertainty, replication state, and limitations. Label synthetic harness checks, single observed runs, and externally authorized replicated results separately. Never upgrade tests or examples into benchmark efficacy.

If no eligible packet exists, title the section `Current Evidence Status`; describe protocols and available contract checks in future/present evidence language, set efficacy and causal conclusions to unknown, report no performance number, and add a result-authorization TODO. Emit a TeX fragment and schema-valid sidecar. Never run experiments or inspect repository files.
