# Hardness-Magnification Bridge Realization

## Candidate Lemma

For the beta-zero parity carrier, a bounded Tseitin self-reduction FormulaEval rule is foldable into the least closed transparent support parser exactly when its child declarations are counterfactually complete before the rule is used. Actual-branch-only pruning is not a valid transparent support interface.

## Definitions

- source object: H_N^SAT(x)=xor_{j<M_N} SAT(G_N(x,j)), with M_N=N^{q+o(1)}, polylog formula length L_N, and generator size N^{rho+o(1)}.
- target object: a same-model nonuniform SIZE upper-bound falsifier for LB_N(1+epsilon) for the carrier H_N^SAT, not a proof of P != NP.
- controlled interface: parse a Psys_sym^{CTSR} proof transcript into a charged row-support cone K_CTSR(pi), then build the induced carrier circuit from generator, row solvers, and sparse row patches.
- target-preserving condition: beta=0, advice-free row declarations, same-theory occurrence expansion, prefix-closed reachable support, and no SAT-truth-dependent hidden pruning.
- counterfactual child: every restriction child, branch guard value, and Tseitin variant that the bounded TSR rule may consult under any local label completion compatible with the visible parent row.
- K_CTSR(pi): the least fixed point generated from the final LB_N line by ordinary bEF dependencies, FormulaEval support pointers, and all counterfactual DTSR children of every reachable DTSR line.

## Assumptions

- Circuit model is nonuniform SIZE over Boolean circuits; proof parsing is uniform in N but the final falsifier circuit may be nonuniform as in the source lower-bound model.
- Length regime has M_N=N^{q+o(1)}, L_N=(log N)^d with d>1, and beta=0 so substituting SAT circuits of size L_N^c costs only N^{o(1)} per surfaced row.
- A DTSR parent row exposes bit fields (row id, formula id, restriction word, branch guard, Tseitin seed, child pointer list, occurrence neighborhood list, and expansion certificate).
- The declaration list is counterfactually complete: for each reachable parent row the parser can enumerate every possible bounded child row before accepting the semantic self-reduction line.
- Sparse row errors E_pi are charged by equality patching O(E_pi N), and the claimed lower-bound threshold is N^{1+epsilon-o(1)}.
- No hidden advice may select rows; if a row is used semantically it must be generated by the transcript and included in Gamma before the rule contributes.

## Definitions

- source object: H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)) with N=2^n, M_N=N^{q+o(1)}, and a Psys_sym^BTRS proof pi of LB_N(1+epsilon).
- target object: the nonuniform Boolean SIZE claim C(H_N^SAT)>N^{1+epsilon-o(1)} and the same-model upper-bound falsifier extracted from pi.
- controlled interface: a finite TransparentRowSupport checker returning parent pointers, a least reachable support cone K_B(pi), enumeration debt U_N(pi), expansion debt X_N(pi), and same-theory bEF splice templates.
- target-preserving condition: every row choice and influence witness is proof-visible, uniformly enumerable without SAT-truth advice, prefix-expanded before semantic use with fresh extension variables, and not supplied by an opaque FormulaEval oracle.

## Assumptions

- Model is nonuniform Boolean SIZE on the beta-zero SAT-parity carrier; proof simulation is an extraction/prefix-splice argument, not a many-one reduction.
- Exponent regime is N=2^n, |pi|=N^{tau+o(1)}, h=N^{eta+o(1)}, size(G_N)=N^{rho+o(1)}, M_N=N^{q+o(1)}, and fixed epsilon>0.
- Uniformity regime is deterministic no-advice parsing from N and pi; selector codes, witness enumerators, and row covers are proof-visible bit strings.
- Same-theory condition requires each FormulaEval line to be replaced by bEF material over the same prefix variables before the line is consumed.
- Naturalness audit is conditional: if the extracted support defines a large constructive useful truth-table property, PRF tension applies; otherwise this is only a proof-system parser theorem.

# MCSP / Meta-Complexity Carrier Transfer

## Candidate Lemma

In Psys_sym^QE, row-set deduplication across quarantined FormulaEval exits is valid only through a prefix-visible RowSetEqualityWitness_N. With such witnesses, the Gamma ledger charges each influencing row to its first syntactic owner; without them, the parser must sum-charge exits or a private-row/unread-enable-bit falsifier exists.

## Definitions

- source object: a bit-explicit Psys_sym^QE proof pi of LB_N(1+epsilon) for H_N^SAT(x)=xor_{j<M_N} SAT(G_N(x,j)), with FormulaEval quarantine blocks, exit lines e, visible row selectors R_e, and optional equality witnesses W_{e,e'}.
- target object: a same-model nonuniform SIZE upper-bound falsifier for H_N^SAT below N^{1+epsilon-o(1)}, obtained from the parsed transcript Gamma_QEOwn(pi), not a proof of P != NP.
- controlled interface: a prefix-visible ownership certificate assigning every influencing row to the first charged exit, and permitting row-set equality only by canonical enumeration or two-sided syntactic inclusion witnesses over explicit row indices.
- target-preserving condition: all row support, ownership, equality, and occurrence-expansion witnesses are advice-free, same-theory, available before first external dependency, and do not use SAT-truth pruning or nonuniform hard-row selection.

## Assumptions

- Circuit target is unrestricted nonuniform SIZE over the H_N^SAT truth-table family; the proof-system parser is Cook-Reckhow uniform and bit-explicit.
- Length regime has M_N=N^{q+o(1)}, generator overhead N^{rho+o(1)}, formula length polylog N, and proof expansion overhead E_pi N charged separately.
- Every quarantine exit dominates all external dependencies of its delayed FormulaEval lines; exits form a prefix-visible dominator forest.
- A RowSetEqualityWitness_N is valid only if pi_{<t} lets the verifier enumerate identical row indices or certify both inclusions without semantic SAT advice.
- Hidden semantic row equality, projected witness equality without dedup proof, and after-the-fact support discovery are not valid transparent support.

## Equations

- row_count: `M_N=N^{q+o(1)}`. Valid when: Valid when N ranges over the beta-zero parity family and the SAT-query generator has the declared polynomial row count.
- owned_gamma: `\Gamma_{QEOwn}(\pi)=\Gamma_{bEF}(\pi)+\sum_e U_e+N^{1+o(1)}\cdot |K^{own}_{idx}(\pi)|+\sum W_e`. Valid when: Applies after every FormulaEval exit has a prefix-visible owner certificate and every cross-exit deduplication uses a RowSetEqualityWitness_N.
- sum_charge_fallback: `\Gamma_{QESum}(\pi)=\Gamma_{bEF}(\pi)+\sum_e \left(U_e+N^{1+o(1)}|R_e|\right)`. Valid when: Requires absence of valid row-set equality witnesses, so syntactically distinct exits cannot share support charges safely.
- same_model_upper_bound: `C(H_N^{SAT})\le N^{\rho+o(1)}+\Gamma_{QEOwn}(\pi)+O(E_\pi N)`. Valid when: Valid when the parser circuit expands only charged same-theory rows and all semantic influence is prefix-visible before use.

- support_density_corollary: `X_N=N^{1+o(1)}|K^{own}_{idx}(\pi)|,\quad |K^{own}_{idx}(\pi)|\ge N^{\epsilon-o(1)} \text{ prevents a subthreshold row-expansion falsifier}`. Valid when: Applies in the support-density corollary after M_N=N^{q+o(1)} and row expansions cost N^{1+o(1)} per charged row.

## Attempted Derivation

- Order FormulaEval quarantine exits by first external dependency time; compute the dominator forest from proof parent pointers and sealed-exit declarations.
- For each exit e, enumerate its visible row set R_e with cost U_e, or charge a full scan; expand every row occurrence used by the same-theory parser at cost N^{1+o(1)} per row.
- Assign first-owner(e,r) to the earliest exit whose prefix-visible row certificate contains r. Later exits may reuse r only if W_{e,f} proves equality or inclusion before the later exit's first external dependency.
- Induct over proof lines: bEF lines preserve Gamma_bEF; quarantined internal FormulaEval lines create no external dependency; a sealed exit adds its U_e, W_e, and first-owned row expansions; external dependencies see only already charged rows.

Blocking gap: A full RowSetEqualityWitness_N theorem for arbitrary semantic or projected selectors is not proved. The derivation is complete for canonical enumerators, bidirectional inclusion certificates, and syntactic first-owner tags; semantic dedup remains quarantined.
