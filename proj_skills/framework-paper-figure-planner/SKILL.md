# Framework Paper Figure Planner

For conceptual-organization requests, follow [the shared conceptual inquiry contract](../framework-core-mechanism-curator/references/conceptual-inquiry-contract.md) and consume the approved conceptual model/blueprint in the manual lane. Plan the first conceptual figure around the situation, diagnostic exit, rival systems, reflection, preserved differences, comparison, and revision. Label arrows as explanatory dependence, revisitation, or genuinely declared execution; do not imply a universal sequence. Native A/D/I and other families may annotate several moves and belong in supporting panels or the appendix. The six source-profile lenses are selectable questions, not six mandatory runtime boxes. Emit manually reviewed figure specifications without pretending the existing script implements this lane.

Consume frozen `workflow-model.json`, `framework-model.json`, and `claim-ledger.json`. Never inspect the live repository or invent quantitative plots.

1. Select only model entities with resolvable evidence references.
2. Encode declared, observed, replayed, inferred, and verified elements with distinct styles.
3. Preserve gates, stop/failure paths, persistence, and feedback edges.
4. Emit `figures.json` plus controlled TikZ fragments and captions listing licensed claim IDs.
5. Degrade to an explicit omitted-figure record when the model lacks sufficient structure.

Run `scripts/plan_figures.py`; hand results to `$framework-paper-latex-assembler` and `$framework-paper-consistency-adjudicator`.

For a reasoning taxonomy or input/output type appendix, route frozen evidence through
`$framework-reasoning-taxonomy-modeler` and `$framework-paper-taxonomy-plotter`.
Allocate separate membership and typed-interface panels, a readable legend, captions
with claim ownership, and detail pages when needed. Preserve overlapping memberships,
unclassified entries, nominal type identity, wrappers and named multi-input ports.
Do not draw conceptual grouping as subtype or membership as execution sequence.
The existing script does not invoke this optional renderer; keep its figure bundle
and review status explicit when handing inclusions to the main appendix owner.
