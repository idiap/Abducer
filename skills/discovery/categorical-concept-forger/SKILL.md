# Categorical Concept Forger

Use category theory as a high-risk conceptual lens, not as ornamental vocabulary. A forge packet is admissible only when a real structural pressure activates the existing categorical lens heuristic, an exact noncommuting diagram is named, and the abstraction produces finite local obligation-bearing structure over the same task without it.

## Reuse Before Forging

1. Start inside `reflective-conceptual-discovery`; preserve its target, conceptual genealogy, current-literature basis, and rival systems.
2. Project the pressure rows through `skills/common/discovery_lens_heuristic.py::build_categorical_pathway_heuristic`. Stop if the deterministic route is not recommended.
3. Reuse `skills/common/task_relation_compiler.py::compile_task_relation` through `skills/common/abstraction_formal_reasoning.py::forge_case_artifact`; then reuse `build_category_model_and_witness` and `validate_category_model` for executable finite law and countermodel checks. Do not hand-author a semantic binding or substitute a prose diagram.
4. Use `abstraction-fit-gap-auditor` to compare the incumbent, local repair, categorical candidate, and a noncategorical alternative.
5. Use `proof-same-domain-transfer-certifier` for every functor or natural transformation presented as theorem transfer.
6. For physics, require `physical-relevance-impact-auditor` before investment. Route Yang--Mills packets through `ym-categorical-hott-physics-bridge`.

## Forge Workflow

1. Freeze the mathematical object, target statement, preserved invariants, and forbidden target changes.
2. Declare typed semantic anchors, one or more categorical task relations (`noncommuting_composition`, `mediating_factorization`, or `functorial_transfer`), the incumbent next decision, and the relation-triggered categorical candidate decision. Compile them with the shared task-relation compiler; a lexical prompt prefix or categorical vocabulary is not a semantic derivation.
3. Name finite object carriers and typed morphisms with total element actions. Define one exact identity per object and a closed pair-composition table, then replay identity, typing, action, and associativity laws before invoking a universal property.
4. State the smallest universal, adjoint, factorization, descent, or functorial claim that would change the route. For the finite universal-property scope, enumerate every mediator candidate and replay its cone, factorization, and uniqueness checks.
5. Exhibit an exact failure witness: two paths with the same source and target, their replayed unequal composite actions, boundary conditions, and registry-bound validator receipt. A slogan such as “the diagram may not commute” is not a witness.
6. Derive only the consequence selected by the compiled categorical relation. Replay the model up to finite carrier isomorphism so harmless relabeling is accepted while a normalized model carrying another task's semantic binding is rejected.
7. Translate the candidate into a physical carrier or an explicit `not_applicable_non_physics:<reason>` marker, target burden, obligation, correction test, and `refine`, `demote`, or `quarantine` decision. Compare the declared incumbent and candidate by decision kind, normalized action, and target burden. Return the candidate only when that substantive tuple changes; otherwise emit typed `quarantine_non_investment`. Every handback keeps formal-elegance, theorem, Yang--Mills, physics-value, and investment authority false.
8. Execute the categorical, HoTT, combined, incumbent, and no-abstraction condition forgers through the existing isolated runtime with six equal-budget deterministic reruns over the same sealed held-out case suite. Bind the exact `case_suite_id` through report, cells, outputs, and ablation summaries; reserve `case_id` for real held-out tasks. Report tasks as clusters and reruns only as repeatability diagnostics—never IID samples or confidence intervals. Compute effects only from exact baseline-treatment repetition intersections. If any arm retains fewer than five executions, hard-fail the comparison and emit only typed replayable failure evidence preserving the complete runtime, every completed sibling, and each failure class/detail; never lower the five-pair floor or emit a net-value number. Decorative, restatement, and sham-abstraction outcomes must be explicit and score zero from replayed structure rather than prose.
9. Hand the result back to reflective synthesis. The forge never promotes truth, novelty, or a theorem by itself.

## Mathematical Object and Invariants

The mathematical objects are the declared domain/codomain objects, morphisms, compositions, and proposed universal construction. Preserve the original target domain, quantifiers, semantics, and physical observables. Record every changed structure; categorical equivalence is not automatically physical or proof-theoretic equivalence.

## Epistemic Discipline

Label epistemic status as `concept_candidate`, `provisional`, `refuted`, or `blocked`. Cite evidence for the pressure, witness, and consequence; list explicit unknowns. The current-literature snapshot remains upstream evidence and cannot be replaced by canonical terminology or elegance.

## Failure/Demotion

Demote or quarantine when the route heuristic is negative, the objects or arrows are metaphors, no native categorical task relation is declared, the diagram lacks an exact noncommutativity witness, the target changes under transfer, the candidate leaves the incumbent decision unchanged, the only gain is compression or elegance, or the matched control achieves the same obligation. A counterexample or failed correction test is reusable negative knowledge.

## Codex Exec Protocol

After generative construction, run the deterministic validator; it checks forge packet v5 and parallel evaluation v4, replays the shared lens heuristic, finite functions, identity/composition laws, the declared finite cone/factorization scope, the registry-bound countermodel, the exact physics handback, auditor receipts, and task-clustered same-suite diagnostics. It certifies only the declared finite local model or countermodel; it does not prove a general universal property or downstream theorem.

```bash
python skills/discovery/categorical-concept-forger/scripts/validate_categorical_concept_packet.py packet.json evaluation.json
```

## Output Contract

Emit one v5 forge packet with finite carriers, total arrow actions, exact identities and compositions, an enumerated finite universal-property scope, the strict task-relation compilation, isomorphism-normalized replay identity, categorical consequence, registry-bound witness, and exact decision handback governed by `task_relation_compilation.schema.json`, `task_derived_formal_delta.schema.json`, and `formal_physics_decision_handback.schema.json`. Successful deterministic validation additionally returns one v2 `formal_lens_execution_receipt` bound to the exact packet-v5 bytes, parallel evaluation v4, dependency authority v2, executable module bytes, current-literature projection, finite model, witness, and handback. The receipt states that production evidence and authority-distinct evaluation are unavailable and grants no theorem, continuum, Yang--Mills, physics-value, investment, or cognitive-independence authority. Because the repository authors the forgers, cases, and evaluator, the result remains internal refinement calibration; `refine` is the highest positive disposition and investment is never authorized here.
