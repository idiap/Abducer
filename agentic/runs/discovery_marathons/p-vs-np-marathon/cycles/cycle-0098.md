# Hardness-Magnification Bridge Realization

## Candidate Lemma

Restricted theorem packet: for the beta-zero SAT-parity carrier, every accepted Psys_bEF proof pi with bit-explicit EF support parses into a charged occurrence/SATeq/bounded-SR_h transcript Q_pi of cost Gamma_bEF(pi). If N^{rho+o(1)}+Gamma_bEF(pi)<N^{1+epsilon-o(1)}, then the source lower-bound assertion LB_N(1+epsilon) is false. This is a valid route-level falsifier theorem, not a proof of P != NP.

## Definitions

- source object: H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with |x|=N, M_N=N^{q+o(1)}, formula length L_N=(log N)^d, and LB_N(1+epsilon) meaning C_N(H_N^SAT)>N^{1+epsilon-o(1)} for nonuniform Boolean circuits.
- target object: a subthreshold circuit upper bound for H_N^SAT that falsifies LB_N(1+epsilon), not an NP not subset P/poly conclusion.
- controlled interface: accepted Psys_bEF proof pi -> bit-explicit extension-DAG parser -> occurrence/SATeq/bounded-SR_h transcript Q_pi -> circuit simulation for H_N^SAT.
- target-preserving condition: beta=0 polylogarithmic SAT instances, fixed exponents q,rho,epsilon, explicit generator size N^{rho+o(1)}, and no uncharged advice beyond pi and the parsed transcript.
- Psys_bEF: EF over Boolean encodings of formulas where every extension variable declares a bit-level dependency circuit or list for the formula bits and row indices it reads.
- SATeq axiom: an explicit equality of two bit-encoded formulas, charged by the parser as a semantic link in S_link(pi).
- bounded-SR_h rule: a self-reduction use with at most N^{eta+o(1)} leaves per supported row and leaf-evaluation overhead N^{tau+o(1)}.
- Gamma_bEF(pi): the sum S_dep(pi)+S_link(pi)+N^{q+eta+tau+o(1)}+E_N N, where E_N is the number of residual rows patched by equality tests.

## Assumptions

- Length regime: N ranges over valid carrier lengths, q,rho,epsilon,eta,tau are fixed constants or o(1)-stable exponents, and all hidden o(1) terms are uniform along this regime.
- Circuit model: source lower bounds and falsifying upper bounds are nonuniform Boolean circuit-size statements at input length N; pi may be fixed for N but may not smuggle an uncharged truth table for H_N^SAT.
- Uniformity/advice status: G_N and the parser are uniform enough to be described in N^{o(1)} bits; all nonuniform information used by the final circuit is included in N^{rho+o(1)} or Gamma_bEF(pi).
- Parser premise: the EF extension-DAG is acyclic, bit-explicit, and transitive dependencies are traversed once in topological order, so sharing is charged once in S_dep(pi).
- Semantic premise: SATeq and bounded-SR_h are the only SAT-semantic principles used; symbolic FormulaEval-SAT comprehension is excluded unless row-expanded and charged separately.
- Barrier status: the lemma is not a natural-property claim and is not an algebrizing proof of a separation; it is a syntactic parsing-to-upper-bound theorem with a private-row falsifier for missing support.

## Equations

# Barrier-Aware Lower-Bound Route

## Candidate Lemma

FormulaEval-SAT boundary lemma: for Psys_sym proofs of LB_N(1+epsilon) over beta-zero H_N^SAT, every FormulaEval-SAT mechanism is either row-instantiated and parsable with Gamma charge, or indexed-semantic and a finite falsifier to surface occurrence completion unless it pays N times its semantic row mass.

## Definitions

- source object: a Psys_sym proof pi of LB_N(1+epsilon) for H_N^SAT(x)=xor_{j<=M_N} SAT(G_N(x,j)), with N=2^n, M_N=N^{q+o(1)}, |G_N(x,j)|=(log N)^{O(1)}.
- target object: a row-faithful occurrence transcript Q_pi which, combined with a generator circuit of size N^{rho+o(1)}, gives a nonuniform SIZE upper bound for H_N^SAT.
- controlled interface: classify each FormulaEval-SAT use as a row-instantiated axiom/proof line/extension rule or as an indexed semantic oracle, and charge the semantic row mass E_N of non-row-faithful uses.
- target-preserving condition: the parser is deterministic, uniform, advice-free, preserves concrete x,j indices, and never replaces indexed FormulaEval-SAT by an uncharged hardwired truth-table oracle.
- bridge observable: RowSet(a) is the set of row indices j whose SAT value is semantically referenced by a FormulaEval-SAT atom or rule a.
- countermodel object: one opaque indexed atom FE(G_N(x,J)) with free row variable J and semantic promise J in [M_N] has O(polylog N) surface size but RowSet=[M_N].

## Assumptions

- Model: nonuniform Boolean SIZE is the target circuit model; Psys_sym is a propositional proof system whose verifier runs in poly(|pi|,log N) without advice.
- Regime: N=2^n, M_N=N^{q+o(1)}, proof length |pi|=N^{tau+o(1)}, formula-evaluation overhead h=N^{eta+o(1)}, and rho<1+epsilon.
- Row-instantiated mode: a FormulaEval-SAT occurrence names a concrete row j, or an explicitly enumerable finite row set, inside the bit encoding visible to the verifier.
- Indexed-semantic mode: a FormulaEval-SAT occurrence quantifies or binds a row variable J and asserts SAT semantics for all J in its RowSet without displaying the row instances.
- Uniformity cutoff: RowSet(a) must be computable from pi and N in time polynomial in its output size; otherwise the expansion theorem is invalid and the mechanism is quarantined as semantic oracle power.
- Non-claim: the lemma does not prove P != NP and does not transfer arbitrary proof-system lower bounds to circuit lower bounds.

## Equations

- expansion_charge: `Charge_{FE}(\pi)\ge N\,E_N(\pi)`. Valid when: Applies after indexed FormulaEval-SAT semantics are converted into row-faithful occurrence transcripts for all N target inputs.

- falsifier_inequality: `N^{\rho+o(1)}+\Gamma_{sym}(\pi)<N^{1+\epsilon-o(1)}\Rightarrow LB_N(1+\epsilon)\text{ is false}`. Valid when: Applies when the transcript-to-circuit simulation is uniform, advice-free, and preserves the exact H_N^SAT target function.

# MCSP / Meta-Complexity Carrier Transfer

## Candidate Lemma

Bit-explicit parser ledger for Psys_bEF^-: for fixed constants epsilon>0 and q,rho,eta,tau>=0, every accepted syntactic Psys_bEF^- proof pi of LB_N(1+epsilon) for H_N^SAT, using only EF extension definitions, witnessed SATeq, and bounded-SR_h with h=N^{tau+o(1)}, has an advice-free parser producing an occurrence transcript Q_pi and a circuit upper bound C(H_N^SAT)<=N^{rho+o(1)}+Gamma_bEF(pi). Hence if this quantity is below N^{1+epsilon-o(1)}, the claimed LB_N is false; in a sound system no true instance has such a low-cost proof.

## Definitions

- source object: a bit string pi verified by Psys_bEF^-(N,epsilon,h), proving LB_N(1+epsilon) for H_N^SAT(x)=xor_{j<M_N} SAT(G_N(x,j)), with M_N=N^{q+o(1)} and polylogarithmic formula encodings.
- target object: an advice-free occurrence transcript Q_pi, support set K_idx(pi), exceptional-row list of size E_N, and an unrestricted circuit for the same Boolean function H_N^SAT.
- controlled interface: a deterministic parser traversing the EF extension DAG, syntactic formula-bit encodings, witnessed SATeq quotient edges, and bounded-SR_h local substitutions while charging dependency, link, support, and exception costs.
- target-preserving condition: the source and target use the same length N and same H_N^SAT; all quotient witnesses are explicit, no FormulaEval-SAT semantic oracle or advice-selected row is used, and q,rho,eta,tau are fixed length-uniform exponents.

## Assumptions

- Proof model: Psys_bEF^- is a Cook-Reckhow bit-level verifier whose line types are EF extension definitions y_t <-> B_t over earlier variables, Boolean derivation lines, SATeq lines with explicit formula-quotient witnesses, and bounded-SR_h rewrite rules touching at most N^{tau+o(1)} occurrence neighborhoods per relevant query layer.
- Circuit model: LB_N(1+epsilon) means unrestricted nonuniform Boolean circuit size greater than N^{1+epsilon-o(1)} for H_N^SAT on n=log N input bits; the derived upper bound is in the same unrestricted circuit model.
- Uniformity and advice status: G_N, the parser, the quotient-witness decoder, and exceptional-row enumeration are E-uniform and advice-free; nonuniformity enters only at the final circuit upper bound by hardwiring the parsed finite transcript.
- Length regime: N tends to infinity along the valid beta-zero carrier lengths, M_N=N^{q+o(1)}, generator size is N^{rho+o(1)}, quotient decoding overhead is N^{eta+o(1)}, and h=N^{tau+o(1)}.
