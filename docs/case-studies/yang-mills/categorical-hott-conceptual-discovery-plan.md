# Category/HoTT Conceptual Discovery Plan

## Executed calibration and authority boundary

The reusable layer executes actual categorical, HoTT, combined, incumbent, and no-abstraction condition forgers through the existing isolated-process portfolio with six equal-budget cells per arm. Every cell receives the same sealed held-out case suite; request, seed, cell, output, callable-source, and evaluator digests are replayable. The report, its attempt/output rows, and every downstream ablation summary bind the same `case_suite_id`; `case_id` is reserved for an actual held-out task. This is a clean v4 contract break because no durable v3 report consumer exists, so no ambiguous compatibility alias is retained. The standard precommitted failure leaves five retained outputs in its arm, while every cell receives a sixty-second wall allowance and the portfolio allowance covers all worker waves. Held-out cases are the reporting clusters; repeated executions of the same sealed case are repeatability checks, not IID observations. No confidence interval or population effect is inferred. Scores derive from replayed finite formal artifacts, and explicit decorative, restatement, and sham-abstraction outcomes must all receive zero structural credit.

Paired effects are computed only on the exact intersection of treatment and no-abstraction repetition IDs. Each paired result carries its matched IDs, matched count, five-pair minimum, and an explicit calibration status. Five or more exact pairs produce descriptive internal-calibration diagnostics. If any arm retains only zero through four executions, the runtime hard-fails after fan-in and emits no comparison report. The exception preserves a separate digest-bound operational evidence packet containing per-arm retention, every failed attempt summary, and the exact runtime/dependency digests, so failure remains inspectable without laundering an underpowered comparison into calibration. The five-pair threshold is never lowered after partial failure.

The formal dependency closure is derived once immediately before factorial fan-out, sealed inside an immutable opaque run context, copied unchanged into every worker and nested witness, and rebuilt immediately after fan-in. Raw self-digested mappings cannot enter the cached path. Report validation rebuilds the closure once more before replay. This run-boundary cache removes repeated import/schema scans from the worker hot path while still failing if any dependency byte, import edge, schema reference, or runtime pin drifts during or after execution.

This is an **internal protocol calibration**, not evidence that category theory or HoTT creates conceptual or physical value: the repository authors the forgers, cases, rubric, and evaluator. Reports therefore carry `investment_authorized: false`, `conceptual_value_authorized: false`, and `physics_value_authorized: false`. They may route reflective refinement, expose broken infrastructure, and produce finite local countermodels. Physics investment requires separately authenticated, authority-distinct evidence; simulations and finite experiments remain secondary tests requested by theory.

## Outcome

Category theory and homotopy type theory become reusable, high-risk conceptual discovery lenses without becoming prestige vocabularies or alternate truth authorities. Their role is to expose compositional, identity, transport, mediation, or coherence structure that changes a theorem or physical route. Yang--Mills receives a separate bridge because an abstract equivalence is not yet a physical equivalence.

## Deep Reflection

The central opportunity is not “apply category theory” or “formalize physics in HoTT.” Those formulations already assume the abstraction is useful. The generative question is narrower and harder: what recurring obstruction becomes visible only when representations and their translations are treated as first-class mathematical objects?

Three distinctions carry most of the value:

1. `representation change` versus `same-domain theorem transfer`;
2. `equality` versus `equivalence` versus `operational indistinguishability`;
3. `beautiful compression` versus `new consequence-bearing structure`.

Category theory is favored when failure lives in composition, mediation, factorization, or a universal interface. HoTT is favored when failure lives in identity, transport, path dependence, descent, or higher coherence. Neither lens is favored merely because several objects can be named as a category or several equivalences can be imagined.

For Yang--Mills, the decisive conceptual question is whether a noncommuting representation/limit diagram or a noncoherent equivalence family localizes a real burden: observable completeness, reflection positivity, regulator-independent continuum coherence, physical-unit rigidity, OS reconstruction, or the spectral conclusion. If not, the abstraction is decorative even when mathematically correct.

## Architecture

```text
current literature + reflective theory state
                |
      shared category/HoTT heuristic
          /                     \
 categorical forge        HoTT forge
          \                     /
    independent parallel branches
          + matched no-abstraction controls
                    |
       conflict-preserving reflection
                    |
       generic target or YM physics bridge
                    |
 fit + same-domain + relevance + correction gates
                    |
  burden/correction/failure handback to theory
                    |
          refine / demote / quarantine
```

The shared `discovery_lens_heuristic.py` remains the only deterministic activation heuristic. The two forgers reuse it, while `abstraction_formal_reasoning.py` supplies finite executable category laws, term/fiber transport, countermodels, and actual condition forgers. `parallel-hypothesis-portfolio` supplies isolation, partial-success retention, and a single reducer; the new skills do not create another parallel runtime. Experiments and simulations remain theory-requested correction probes after a mature burden is stated.

## Typed Boundaries

`abstraction_parallel_evaluation.schema.json` v4 distinguishes suite identities from task identities and keeps five exact pairs as the non-negotiable refinement-calibration floor. Historical or independently constructed insufficient packets remain representable for conservative validation, but the active factorial runtime never emits one: fewer than five retained executions in any arm is a hard operational failure. Its separate `abstraction_evaluation_failure.schema.json` evidence contains the complete validated runtime, sealed basis and rubric, every attempt, every completed sibling ID, each failed receipt's class/detail, and the exact unexpected-failure set. Replay requires every predeclared failure to have an allowed non-completed runtime status. Successful diagnostics remain deterministic, non-IID, non-population summaries under the internal evaluator.

`abstraction_forge_packet.schema.json` v4 covers both generic lenses. Category packets declare finite carriers, total morphism actions, exact identities/compositions, and an enumerated finite cone/factorization/uniqueness scope. HoTT packets declare finite terms, total map and inverse actions, an indexed path-fiber table, source/target predicate fibers, term-level paths and homotopies, parallel coherence boundaries, missing terms, and explicit truncation state. Because this finite representation gives paths term rather than recursively typed path endpoints, every path and indexed fiber is exactly level 1; higher coherence remains represented by typed coherence cells. Every path must reference exactly one indexed fiber whose ambient type, term endpoints, and optional Boolean truth boundary equal the path row; foreign, missing, mismatched, and unused fibers fail. Both lenses bind an exact registry-replayed witness, carrier/burden/obligation/correction translation, mandatory physics handback, and task-clustered repeatability diagnostics.

`ym_categorical_hott_bridge.schema.json` v6 restores the full physics burden: the exact target, `R=(K,A_phys,S,D,G,L,Q)`, finite physical-carrier actions and laws, derived carrier mappings, source-specific inference rows with no fabricated continuum coverage, an absence-only continuum-authority gate, bidirectional structure-specific corrections, a same-domain certificate, complete quantifier ledger, nine registered replayable calibration runners, and a standalone ordered fourteen-row physics handback. Its decision is refinement, demotion, or quarantine—never investment.

The semantic validator adds conditions that JSON Schema alone cannot express:

- the stored heuristic must exactly match a fresh call to the shared helper and must recommend the lens;
- finite category actions must be total and typed; identities, declared compositions, associativity, cone checks, factorization, and uniqueness must replay over the complete declared finite scope;
- finite HoTT maps, inverse laws, exact indexed path fibers, predicate-fiber transports, homotopies, coherence boundaries, missing terms, and truncation state must replay;
- parallel paths must share endpoints and the registry-bound countermodel must compute distinct composites or an explicit term/fiber obstruction;
- physics carriers must name a gauge, observable, Schwinger, Wilson, Hilbert, Hamiltonian, lattice, continuum, correlation, field, measure, or algebra object;
- a promoted generic packet must expose an obligation unavailable to the matched control;
- task-clustered score diagnostics and exact repetition intersections must recompute; fewer than five retained executions hard-fail with separate operational evidence, deterministic reruns may establish repeatability only, and the packet cannot authorize investment;
- the YM source and target must independently remain four-dimensional pure Yang--Mills;
- all nine YM calibration outputs must replay against their exact runner/input/executable and bounded dependency digests; declarative topological and regulated-lattice checks are `boundary_fixture` rows, never theorem/countermodel certificates, while planned rows require an exact commission and no result;
- the full false-positive calibration bank and all downstream physics gates must be present.

## Parallel Discovery Route

1. `high-risk-hypothesis-forger` may emit category, HoTT, incumbent, local-repair, and nonabstract rival hypotheses.
2. The shared heuristic rejects unmotivated lens branches before maturation.
3. `parallel-hypothesis-portfolio` runs each surviving candidate with immutable inputs. A category branch, a HoTT branch, their combination, and incumbent/no-abstraction controls receive the same sealed case suite but separate seeds, cells, artifacts, source digests, and receipts.
4. Branches may share only the frozen target, literature snapshot, and pressure packet. They do not see sibling conclusions before reduction.
5. Reflective synthesis preserves a category/HoTT conflict when the lenses expose different burdens; it does not scalar-rank elegance.
6. For Yang--Mills, only the bridge packet may feed target-specific proof planning. Generic forge packets remain conceptual evidence.

## Held-Out and Negative-Control Matrix

The focused suite covers category and HoTT in both physics and nonphysics domains. Negative controls tamper finite actions, identities, cone scope, inverse maps, fibers, coherence boundaries, truncation, witness receipts, arm/cell bindings, executable digests, calibration replay, physical carriers, or the Yang--Mills domain. Decorative, restatement, and sham-abstraction outputs are valid controls only when their structural score is exactly zero. These are semantic failures, not merely missing fields.

The with-versus-without-abstraction ablation uses the same target and evidence and scores:

- burden closure;
- obstruction localization;
- consequence yield;
- unification without erasure;
- correction specificity.

This is an internal route-refinement test, not evidence that the abstraction is true, historically novel, generally valuable, or population-valid. Every physics-facing result first returns its exact burden, correction tests, and failure witness to reflective theory.

## Non-Claims

This slice proves only that declared finite local models, laws, countermodels, runner outputs, and receipt bindings replay. It does not prove a general categorical universal property, a model of HoTT or univalence, a physical duality, continuum Yang--Mills, or a mass gap. It does not make category/HoTT mandatory for every discovery problem, add a core operator, alter evaluator authority, or let an experiment select the governing theory.
