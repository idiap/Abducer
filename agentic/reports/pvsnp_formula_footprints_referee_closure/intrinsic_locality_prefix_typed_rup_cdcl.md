# Intrinsic-Locality Prefix-Typed RUP-CDCL

Status: `proved_in_revised_tex`

TeX label: `cor:intrinsic-locality-prefix-typed-rup-cdcl`

Role: `proof_system_bridge`

This packet records the positive counterpart to the prefix-typed support-witness
necessity theorem.  Public label syntax and append-only RUP checking do not
certify auxiliary support-locality by themselves.  This corollary states the
extra invariant that is sufficient: auxiliary clauses must be introduced by
fixed public completion-stable rules whose support sets are checker-computable
from the displayed rule instance.

## Theorem Summary

Measured object: prefix-typed append-only RUP-CDCL proof object with public
completion-stable auxiliary rule instances instead of separate support-local
auxiliary witness fields.

Conclusion: the carrier-independent audit upgrade criterion applies with linear
audit budget when auxiliary support-locality is generated by the proof system's
ordinary rule syntax.

Proof-system status:
`positive_for_intrinsic_locality_prefix_typed_append_only_RUP_CDCL_not_raw_untyped_or_deletion_bearing_RUP_DRUP`.

## Proof Skeleton

- parse formula-label support using the public syntactic namespace;
- scan the append-only clause database and RUP witnesses;
- compute each touched auxiliary support set from the displayed rule instance;
- invoke the fixed completion-stable soundness theorem for each auxiliary rule;
- form the union support \(S_\pi\);
- apply the carrier-independent audit upgrade criterion;
- use the linear audit budget to derive the \(n^{a-o(1)}\) proof-length lower
  bound.

## Nonclaims

This theorem does not prove a lower bound for raw DIMACS, untyped raw RUP/DRUP,
deletion-bearing RUP/DRUP without retained support, arbitrary CDCL,
provenance-free learned clauses, Frege, Extended Frege, IPS, arbitrary
compressed proofs, or proof systems whose auxiliary clauses are justified by
hidden semantic choices rather than fixed public completion-stable rules.

## Coherence

Closest literature object: typed clausal proof systems with public rule schemas,
role-typed variables, and checker-visible RUP certificate checking.

Before: the support-local auxiliary witness remained a side field even after
public label typing removed the decoder.

After: the witness is replaced by ordinary proof syntax when the proof system
has fixed public completion-stable auxiliary introduction rules with
checker-computable support.
