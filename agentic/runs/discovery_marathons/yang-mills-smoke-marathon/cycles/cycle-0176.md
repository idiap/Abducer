# Reflection-Positivity Closed-Cone Topology: collar trace bridge

## Candidate Lemma

Collar-to-plane OS positivity lemma. Let S be the continuum gauge-invariant Schwinger functional obtained as the cutoff limit. Suppose fixed-collar reflected quadratic forms are nonnegative, and suppose every finite reflected quadratic form on a mirror-smooth positive-time core has a trace modulus as the collar is collapsed to the reflection plane. Then S is OS-positive on that core. If the core is OS-norm dense in the intended gauge-invariant positive-time algebra with no boundary renormalization, then S is OS-positive for the same continuum Yang-Mills theory, not for an enlarged boundary theory.

## Definitions

- source object: a cutoff net of reflection-positive gauge-invariant Schwinger functionals S_{a,L} on lattice/cell observables, together with embeddings iota_{a,L} of a fixed continuum positive-time core into the regulated observable algebra.
- target object: an OS-positive continuum Schwinger functional S on the locked gauge-invariant positive-time algebra A_+, from which the OS Hilbert space, vacuum, and positive time-translation semigroup can be reconstructed.
- controlled interface: regulated reflection-positive Schwinger forms -> OS-positive continuum Schwinger functions by first passing positivity at positive distance delta from the reflection plane, then proving a trace limit as delta downarrow 0.
- same-theory condition: the maps iota_{a,L}, the collar maps T_delta, and the continuum inclusion of the mirror-smooth core into A_+ commute in the limit and introduce no reflection-plane counterterm, no changed Wilson-loop renormalization, and no quotient/enlargement of the gauge-invariant algebra.
- A_{+,delta} is the subalgebra generated by gauge-invariant observables whose Euclidean supports have time-coordinate at least delta > 0.
- A_+^{ms} is a mirror-smooth positive-time core: local renormalized gauge-invariant composites are smeared by C_c^infty functions supported in t >= 0 and flat at t = 0, and loop/cylinder observables have doubled reflected contours with no corner at the reflection plane.
- T_delta: A_+^{ms} -> A_{+,delta} is a collaring operation, e.g. normal translation/smoothing into t >= delta, chosen so T_delta F converges to F in the core topology as delta downarrow 0.
- Q_S(F,c) denotes the finite OS quadratic form sum_{i,j} conjugate(c_i)c_j S(Theta F_i F_j), where F_i are positive-time gauge-invariant observables.

## Assumptions

- For every fixed delta > 0 and every finite family F_i in A_+^{ms}, the RG cutoff-removal topology is strong enough to pass the regulated inequality Q_{a,L}(T_delta F,c) >= 0 to Q_S(T_delta F,c) >= 0.
- Trace modulus: for every finite family F_i in A_+^{ms} there exists omega_F(delta) -> 0 such that |Q_S(T_delta F,c) - Q_S(F,c)| <= omega_F(delta) sum_i |c_i|^2 for all coefficient vectors c.
- The same reflection Theta acts before and after cutoff removal under the chosen embeddings; in particular, no gauge fixing, quotienting, or boundary projection changes the test algebra.
- A_+^{ms} is dense in the intended OS seminorm after quotienting null vectors, and the density is implemented by the same continuum Schwinger functional S rather than by adding boundary observables.
- The finite matrices with entries S(Theta T_delta F_i T_delta F_j) have finite limits as delta downarrow 0.

## Equations

- fixed-collar positivity: `Q_S(T_\delta F,c)=\sum_{i,j}\overline{c_i}c_j\,S(\Theta T_\delta F_i\,T_\delta F_j)\ge 0`. Valid when: Valid after cutoff removal for each fixed delta > 0, provided RG convergence controls the reflected collar probes.
- trace modulus: `\left|Q_S(T_\delta F,c)-Q_S(F,c)\right|\le \omega_F(\delta)\sum_i |c_i|^2,\qquad \omega_F(\delta)\downarrow 0`. Valid when: Valid when the continuum Schwinger distributions have a boundary trace on the chosen mirror-smooth core and no reflection-plane anomaly is present.
- collar limit: `Q_S(F,c)=\lim_{\delta\downarrow 0}Q_S(T_\delta F,c)\ge 0`. Valid when: Valid once both fixed-collar positivity and the trace modulus hold for the same finite family F_i and coefficients c_i.
- boundary-defect falsifier: `\lim_{\delta\downarrow 0}Q_S(T_\delta F,c)=Q_S(F,c)+B_{\partial}(F,c)`. Valid when: This is the obstruction form; if B_partial is nonzero and not part of the original observable definition, the bridge proves positivity only after changing the theory.

## Attempted Derivation

- Fix a finite family F_1,...,F_N in the mirror-smooth positive-time core A_+^{ms} and coefficients c_i.
- For every delta > 0, T_delta F_i lies strictly in the positive-time collar algebra A_{+,delta}. The regulated lattice or cell theory gives Q_{a,L}(T_delta F,c) >= 0 by reflection positivity.
- Use the cutoff-removal topology on fixed-collar reflected probes to pass to the continuum: Q_S(T_delta F,c) = lim Q_{a,L}(T_delta F,c) >= 0. This step is valid precisely because the supports stay a positive distance from the reflection plane.
- For the local-composite subcore, write each matrix entry as a finite sum of continuum distributions applied to translated test functions. Since f_delta -> f in C_c^infty, distributional continuity gives S(Theta T_delta F_i T_delta F_j) -> S(Theta F_i F_j). Hence the trace modulus holds for this subcore.
- For the Wilson-loop part, reduce the same limit to two requirements: continuity of renormalized loop correlations under C^2 mirror-smooth deformation, and convergence of renormalization ratios Z_a(C_delta)/Z_a(C) to 1. If both hold, the same trace modulus follows.
- Taking delta downarrow 0 in Q_S(T_delta F,c) >= 0 gives Q_S(F,c) >= 0. Density of A_+^{ms} in the OS seminorm then extends positivity to the full intended gauge-invariant algebra.

Blocking gap: The derivation is complete for a purely local smooth-smeared core once composite Schwinger distributions exist, but it lacks a Yang-Mills theorem proving loop-space continuity and no reflection-plane boundary renormalization for Wilson-loop/cylinder observables produced by the RG construction.

## Falsifiers

- A concrete falsifier would be a mirror-smooth loop family C_delta whose continuum Wilson-loop correlation has a nontrivial limiting cusp or boundary anomalous factor, so that Z_a(C_delta)/Z_a(C) does not tend to 1.
- If the RG compactness topology controls only observables separated from t = 0 and gives no distributional extension to test functions flat at the reflection plane, then even the local-core trace modulus is not valid.
- If the positive-time test algebra after cutoff removal includes boundary observables or removes null states differently from the regulated gauge-invariant algebra, fixed-collar positivity does not certify OS positivity for the same theory.
- If curvature-contact terms supported at the reflection plane appear in limits of S(Theta T_delta F_i T_delta F_j), then the limiting quadratic form is Q_S plus a boundary defect B_partial, not the desired Q_S.
- If Wilson loops are not continuous under the needed C^2 collar deformation, the closed-cone argument remains formally true but applies only to a smaller collar algebra.

## Learning

Cycle 176 separates the trace problem into a solved model piece and a genuine Yang-Mills obstruction. For local gauge-invariant composites smeared by smooth functions flat at the reflection plane, the collar trace is just distributional continuity, so OS positivity can be extended there by a valid limiting argument. The difficult part is therefore not the closed cone and not all boundary contact in general; it is specifically the Wilson-loop/nonlocal sector, where collar collapse can create cusp factors or boundary renormalizations. The branch has learned a sharper falsifier: find a nontrivial renormalization ratio Z_a(C_delta)/Z_a(C) in a reflected loop family, and the same-theory OS bridge fails.
