# Timeline Contribution Stater

## Workflow

Use the contribution monitor and strategy judge to state contributions as scoped scientific claims:

1. Read the active narrative goal lock and reject candidates outside its paper subgoal.
2. Name the strongest contribution candidate.
3. State the smallest honest claim.
4. Explain why it is independently valuable even if the main problem remains open.
5. State what would validate or falsify it.
6. State the overclaim boundary.

## Epistemic Discipline

Mark each contribution as paper-note-ready, developing, validation-needed, blocked, or demoted. Cite the source candidate ID, cycle IDs, strategy-judge window, and validation obligations.

## Output Contract

Return: contribution list, novelty argument, explanatory power, implications, validation burden, overclaim boundary, evidence citations, epistemic status, and validation handoff.

## Failure/Demotion

Demote a contribution when it has no precise object, no validation path, no target alignment, no novelty boundary, or only repeats workflow mechanics.

Also demote a contribution when it only adds more exploration detail without changing the locked theorem, worked example, transfer certificate, prior-art boundary, or honest claim.

## Validation Handoff

Require the paper validator to find at least three stated contributions with explicit evidence and at least one overclaim boundary.
