# Archive

Find historical material and distinguish plans from current behavior. This section is for readers learning or using Abducer.

Historical material is retained for provenance. A plan is a proposal until its
implementation and checks are evidenced; a generated snapshot is not a current
authority. Start with the current [documentation index](../README.md) for supported
entrypoints. No existing specialist document is removed by this organization.
