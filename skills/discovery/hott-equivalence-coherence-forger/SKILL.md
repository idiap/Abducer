# HoTT Equivalence Coherence Forger

Use HoTT as an identity-and-coherence discovery lens. Do not upgrade analogy, isomorphism, gauge equivalence, or representational similarity into a path or univalence claim without a typed construction and an exact obstruction.

## Reuse Before Forging

1. Enter from `reflective-conceptual-discovery` with a frozen target, current-literature basis, conceptual pressure, and rival systems.
2. Project pressure rows through `skills/common/discovery_lens_heuristic.py::build_hott_pathway_heuristic`; stop if it does not recommend the lens.
3. Reuse `skills/common/task_relation_compiler.py::compile_task_relation` through `skills/common/abstraction_formal_reasoning.py::forge_case_artifact`; then reuse `build_hott_model_and_witness` and `validate_hott_model` for executable finite term, fiber, transport, and countermodel checks. Do not hand-author a semantic binding or substitute path vocabulary for actions.
4. Compare the incumbent and candidate with `abstraction-fit-gap-auditor`.
5. Send every transport claim through `proof-same-domain-transfer-certifier`.
6. For physics, require `physical-relevance-impact-auditor`; use `ym-categorical-hott-physics-bridge` for Yang--Mills.

## Forge Workflow

1. Freeze the mathematical object, target, invariants, and forbidden target changes.
2. Separate definitional equality, propositional identity, equivalence, analogy, and experimentally indistinguishable presentations.
3. Declare typed semantic anchors, one or more HoTT task relations (`identity_transport`, `equivalence_coherence`, `path_independence`, or `descent_coherence`), the incumbent next decision, and the relation-triggered HoTT candidate decision. Compile them with the shared task-relation compiler; a lexical prompt prefix or HoTT vocabulary is not a semantic derivation.
4. Declare finite type terms, total map actions, inverse equivalence actions, source and target predicate fibers, an exact indexed fiber for every accepted term-level path or homotopy, transports, coherence cells, and an explicit applied-or-deferred truncation policy. This finite contract gives paths term endpoints, so paths, inverse homotopies, and their indexed fibers are exactly level 1; level 2 belongs to coherence cells unless recursively typed path endpoints are introduced. A path's ambient type, term endpoints, and optional truth boundary must equal its indexed fiber.
5. Replay inverse laws, term and fiber transport, path composition, pointwise homotopy boundaries, and missing terms. Exhibit an exact noncoherence witness: parallel composites with one source and target, explicit unequal transported fibers or obstruction class, boundary conditions, and a registry-bound validator receipt.
6. Derive only the consequence selected by the compiled HoTT relation. Replay the model up to finite carrier isomorphism so harmless relabeling is accepted while a normalized model carrying another task's semantic binding is rejected.
7. Translate every candidate into a physical carrier or `not_applicable_non_physics:<reason>`, target burden, obligation, correction test, and refine-or-demote decision. Compare the declared incumbent and candidate by decision kind, normalized action, and target burden. Return the candidate only when that substantive tuple changes; otherwise emit typed `quarantine_non_investment`. Every handback keeps formal-elegance, theorem, Yang--Mills, physics-value, and investment authority false.
8. Execute the same five actual condition forgers, with six equal-budget deterministic reruns over one sealed held-out case suite. Bind one exact `case_suite_id` across the report, cells, outputs, and ablation summaries, while `case_id` continues to name only held-out tasks. Cluster reporting by task and use reruns only to expose repeatability; do not calculate population confidence intervals. Require five exact baseline-treatment repetition pairs before any refinement signal; hard-fail below five retained executions in any arm while preserving separate digest-bound failure evidence. Require explicit zero-credit decorative/restatement/sham outcomes, executable callable digests, predicates, maps, equivalences, transports, indexed homotopy fibers, pointwise homotopies, parallel coherence boundaries, missing terms, and a truncation boundary; the calibration cannot establish HoTT value.
9. Return the packet to reflective synthesis; proof, truth, novelty, and empirical authority remain downstream.

## Mathematical Object and Invariants

The mathematical objects are the declared types, identity types, equivalences, transport maps, and coherence cells. Preserve the target domain, quantifiers, observables, and operational distinctions. Never erase physically distinct sectors or theorem hypotheses by calling them equivalent.

## Epistemic Discipline

Use `concept_candidate`, `provisional`, `refuted`, or `blocked` epistemic status. Cite evidence for the pressure, exact witness, and consequence; record explicit unknowns. A literature rebase and domain-specific review remain mandatory before investment.

## Failure/Demotion

Demote or quarantine if equality, equivalence, and analogy are conflated; if no native HoTT task relation is declared; if higher paths do no work; if the noncoherence witness is merely verbal; if transport changes domain or target; if the candidate leaves the incumbent decision unchanged; if the control route reaches the same obligation; or if elegance is the only value. Preserve counterexamples and failed correction tests as negative knowledge.

## Codex Exec Protocol

After the generative step, run the deterministic validator. It checks forge packet v5 and parallel evaluation v4, then replays the shared HoTT lens heuristic, finite term/map and inverse laws, predicate-fiber transport, homotopy/coherence boundaries, truncation state, registry-bound noncoherence countermodel, exact handback, and task-clustered same-suite diagnostics. It certifies only this finite local term/fiber model; it does not prove univalence, general coherence, or a downstream theorem.

```bash
python skills/discovery/hott-equivalence-coherence-forger/scripts/validate_hott_coherence_packet.py packet.json evaluation.json
```

## Output Contract

Emit one v5 forge packet with finite terms, total maps, executable inverse and fiber actions, exact indexed fibers, parallel coherence boundaries, explicit truncation state, the strict task-relation compilation, isomorphism-normalized replay identity, HoTT consequence, registry-bound witness, and exact decision handback governed by `task_relation_compilation.schema.json`, `task_derived_formal_delta.schema.json`, and `formal_physics_decision_handback.schema.json`. Successful deterministic validation additionally returns one v2 `formal_lens_execution_receipt` bound to the exact packet-v5 bytes, parallel evaluation v4, dependency authority v2, executable module bytes, current-literature projection, finite model, witness, and handback. It explicitly records unavailable production and authority-distinct evidence and grants no theorem, continuum, Yang--Mills, physics-value, investment, or cognitive-independence authority. The output is internal-refinement-only; it cannot authorize investment.
