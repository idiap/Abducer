## Documentation conventions

Authored guides explain current behavior; registries and source contracts define exact
runtime details. Generated catalogs and reports are derived views. Plans, proposals,
archived pages, and historical snapshots do not by themselves establish implemented
capability or scientific validity. Check each page's stated scope and status.

Existing specialist paths remain stable to preserve links, provenance, and detail.
New onboarding and navigation use the nine areas above. See
[documentation maintenance](development/documentation.md) before reorganizing content.
